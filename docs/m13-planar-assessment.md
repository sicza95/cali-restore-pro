## Coordinate and storage contract

- The immutable authoring frame is the main original's upright working raster. Its top-left pixel edge is `(0,0)`, x increases right, and y increases down. Dimensions come from the authenticated M-12 manifest. RAW-backed frames preserve the embedded-preview flag and describe preview pixels.
- Source-ID-scoped assessments are optional in version 1 projects. Apply saves an encrypted project revision. Preparation edits preserve canonical masks. Rejected commands and cancelled inspector drafts leave committed data intact. Portable restore remaps source IDs inside assessments along with the original attachments. Changing which photo is the mapping reference selects that photo's own assessment.
- Closed vector paths use Float64 coordinates and nonzero winding. Opposite winding represents holes and winding multiplicity counts once. The area kernel integrates selected intervals in slabs split at segment endpoints and crossings. Straight edges remain straight under projective transforms. The curve adapter subdivides cubic segments with a caller-supplied error budget in the canonical frame.
- The active main crop intersects the master mask after both are mapped to the analysis plane. An absent master uses the full main raster. An explicit empty master measures zero. Reopening the crop restores previously clipped coverage from the same stored paths. Layer quantities apply this boundary, damage categories union all damage descendants, and overall damage unions every damage mask. Phase masks have independent quantities. Display appearance and working tile resolution are outside the area calculation.
- Preparation supports crop, rotation, horizontal flip, horizontal shear and a bounded projective tilt. Rectify applies the inverse of the selected tilt about the crop centre. Singular matrices and transforms with a projective horizon through their domains are rejected. View zoom, pan and rotation are separate from preparation.
- Align accepts two corresponding landmarks, an optional translation refinement and a partial usable region. The accepted detail mapping is stored in the immutable authoring frame, so changes to main preparation compose with it. Changes to detail preparation require a fresh acceptance. Authoring points must lie inside both the detail's accepted region and its crop, then map within the main crop. Reference-only fallback removes authoring permission. Alignment never changes existing shared mask coordinates.
- The automatic worker looks for translation consensus among textured, approximately same-scale proxy patches. It proposes landmarks for inspection, provides a cancellable job and falls back to manual when confidence is insufficient. Manual fitting uses a similarity transform. Scale and rotation are supported by manual correspondences, while automatic matching is qualified only for the synthetic overlap case.
- Direct dimensions calibrate independent axes against the bounding extent of the prepared crop. Reference lines use their projected horizontal and vertical spans and require both known lengths. Calibration retains the input lengths, unit, endpoints when supplied, source and analysis-frame revision. Main preparation changes mark physical calibration for review. Relative coverage remains available when the denominator is positive. Canonical physical quantities use m², while the workspace follows inherited or overridden metric/imperial settings.
- The worker produces quantities tied to project, surface, frame, calibration and policy revisions. Unavailable, pending, stale, invalid and failed values are distinguishable from valid zero. The segment integration kernel admits up to 4,096 combined edges and bounds intersection and integration work. Calculations beyond those budgets return a failed state. Remaining scale and physical-device checks include dense authored masks and sustained editing.
