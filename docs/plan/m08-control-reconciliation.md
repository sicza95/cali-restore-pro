# M-08 route and control reconciliation

The [workflow inventory](workflows-and-controls.md) specifies the intended controls. The [application registry](../../src/ui/account-access/application-controls.ts) collects the production contracts by composition. IDs identify an action or query and may repeat across authorized rows. The same ID has the same contract in EN and HU. The separate [Storybook tool registry](../../src/ui/controls/tool-rail/constants.ts) describes the synthetic composition. Fields and confirmations within a single platform submission share its authorization and failure boundary.

Project photo, drawing, measurement, checkpoint, pattern, estimate and output reviews stay within their explicit adapters. Applying a draft in these views changes review state. Durable project data and revision acknowledgments come from the existing encrypted storage or service transactions. Invitations open scoped samples through their actual grants. Production readiness also depends on deployed retention/restore evidence, independent cryptographic review and physical iPad, Pencil and Safari qualification.
