# M-16 · Measured estimates and draft outputs

The implementation starts from `337f7b8180630e0786e999267edcb03b26fd667a`. GnuPG verified the M-15 signing key and GitHub reported the same commit as Verified at the tip of `main`. See the [M-15 evidence](m15-surface-recovery.md).

## Integrated workflows

- Estimate phases select a surface, current assessment or named checkpoint, and a committed phase layer. Editing and independent layer cloning take place in the surface editor. The estimate worker uses calibrated crop/master intersections and preserves the project, surface, photo, assessment, preparation and calibration revision in the quantity provenance. Time mode retains entered hours and requires acknowledgement when measured area changes. Productivity mode recalculates. Pending marks and invalid calibration cannot supply an area. Previously issued versions remain immutable.
- Reports select the current mapping assessment or named checkpoints and can compare two selected versions. Preview and export share the same measurement rows, including assessment provenance, calibrated extent, converted areas, coverage and primary-minus-comparison totals. Stored sample selectors migrate to current/no comparison. A missing real checkpoint stays unavailable.
- PDF, SVG and PNG use the assessment's committed visible layer styles, including embedded repeating patterns. Map vectors are clipped to the assessed area before encoding. Selected reference attachments are downsampled to at most 640 pixels on the long side and re-encoded as JPEG. CSV and XLSX retain structured measurement rows and selected reference ordinals. Editable XLSX uses the issued inputs, area and assessment label. An issued quote is included only when its surfaces and measured assessment selections are in report scope.
- Output downloads remain labelled drafts. Existing account-local report authorization and the assessment, summary and full estimate grants continue to apply.
