## Implemented contracts

- UI-independent `src/platform/estimates` implements `restoration-v1` using exact BigInt rational arithmetic, reduced by greatest common divisor. Decimal inputs permit up to 18 fractional places; scientific/nonfinite values fail. Computation retains rational precision until money rounding. Derived quantities serialize at 18 places; display trims trailing zeroes. No new dependency.
- **Engineering decision:** midpoint rounding is half-away-from-zero, including negative discounts; this is not presented as an owner-confirmed tax rule. Currency minor-unit precision comes from `Intl.NumberFormat` and is captured in results. Reproducing versions across changed runtime currency definitions needs migration consideration.
- Each work/material/extra component rounds independently; sum rounded components, independently round same-base signed adjustments, then round tax. Adjustments never compound or change labour. Tax enabled and configured rate remain independent.
- Hourly/fixed/area prices use the same effort rules. Productivity computes `A/S×F`; time mode preserves final hours. Keep/Adjust/Cancel uses `T×new F/old F`. Materials, fixed prices and area prices are not multiplied by effort.
- Measurement v1 binds project/object/surface/phase/independent scope, committed revision, calibration, physical area/unit, validity and fixture/committed source. Missing geometry is never zero. Manual time/fixed prices survive unavailable area; valid zero area differs from missing. Zero time does not invent productivity.
- `receiveMeasurement` preserves final time and flags review on physical-area change, or preserves productivity and recalculates hours. Exact unit normalization converts productivity/area prices without false area-change warnings. It is not yet wired to a real provider. View navigation/detail alignment must not publish measurements.
- Selected object phases/extras are included; selected project extras are added once at full value. Excluded/archived records remain saved. Fixed extras can have optional labour; rental cost adds no automatic hours. Currency mismatch blocks calculation until explicit clearing/re-entry of prices. Issued versions retain original currency.
- IndexedDB v6 adds separate `encrypted-estimates` and `encrypted-estimate-presets` stores. Existing authenticated encrypted transactions enforce account binding, distinct HKDF/AAD purpose domains, revision compare-and-swap, vault stamp and lock abort signals. No plaintext content reaches server metadata.
- Explicit save/issue and reopen hydrate the last saved draft, not unsaved edits. Snapshots capture input selection, rates/productivity and preset versions, factor/mode, units/currency, measurement and calculation/rounding provenance. Repository rejects changed prior snapshots and input/result mismatch. Save failure retains form inputs; stale writes require reopen.
- Private presets support append-only versions, rename/value edits/archive. Phases create and apply presets by copying effective values/version references. Library edits cannot rewrite estimates. Presets remain device-local.
- Issued summary/full publication uses existing independent HPKE grant envelopes bound to account/project/invitation/scope. Activation and added-scope publication read issued estimates; missing issued data fails closed. M-06/M-08 synthetic arrays remain explicitly supported for regression fixtures; history remains its prior sample adapter.
- Summary is an allowlist: object subtotals, aggregate project extras/adjustments, before-tax/tax/final, currency/version/freshness/provenance. No hours, detailed materials, rates, phase calculations, productivity, preset IDs or assumptions. Summary parsing rejects additional fields; summary readers do not recalculate. Changed project revision or saved draft publishes stale provenance until authorized reissue.
- Full readers receive detached issued data; assessment remains a separate payload. Independent assessment/full-estimate edit rights, scoped collaborative writes and already-active same-scope grant refresh are not implemented by this slice.
